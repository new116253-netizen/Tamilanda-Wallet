About Tamilanda Wallet and how the app is structured

👑
Tamilanda Wallet
Private • Local First • Offline Ready
Everyday money, organized.
A mobile-first wallet built to keep your accounts, transactions, EMI records, buyers, IDs and personal money tracking in one place.
● PWA / Android WebView ready

What this app does

🏦
Accounts
Track bank, cash, UPI and wallet balances.
📒
Transactions
See money paid, received and transferred.
💳
EMI Tracking
Manage active EMIs, payments and remaining amounts.
🆔
My IDs
Keep ID inventory with buy, sell, notes and status.
📊
Reports
Review cash flow and spending patterns.
☁️
Backup
Export and restore your local wallet data.

App Architecture

📱
Mobile-first PWA
The project is structured as static HTML/CSS/JS with PWA/service-worker support and a main index.html entry point.
🗃️
Local wallet data
Core finance records are maintained in browser localStorage under the Tamilanda Wallet storage key.
🧠
Shared app logic
The shared JavaScript layer exposes the wallet data API, calculations, transaction helpers, account helpers and navigation helpers.
